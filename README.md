## 快速开始

```bash
cd pyproject01
.venv\Scripts\activate            # Windows 激活虚拟环境
python "01_数据存储与运算/009.核心语法-数据存储与运算-字面量练习题.py"
```

每章按主题独立，可直接跳章；建议先读文件头部知识点，再运行示例，最后完成文件尾部的练习题。

## 常见问题

- **pytest 报 "No module named '2xx'"**：课程文件名以数字开头，需加 `--import-mode=importlib`：
  `pytest "214.测试与工程化-pytest入门练习题.py" --import-mode=importlib -v`
- **Matplotlib 中文变方块**：
  `plt.rcParams["font.sans-serif"] = ["Microsoft YaHei"]`、`plt.rcParams["axes.unicode_minus"] = False`
- **GUI 窗口一闪而过**：308-315 课默认演示模式会自动关窗；把 `AUTO_DEMO` 改成 `False`，或删除 `root.after(...destroy)` 即可手动操作
- **Git 课程提示目录已存在**：课程在临时目录 `git_demo_2xx/4xx` 中运行；若上次异常中断，删除对应目录即可（源码内已用 `force_rmtree` 处理只读对象）
- **pip 安装慢/断连**：使用清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple`
- **虚拟环境位置**：`pyproject01/.venv`，不污染系统 Python；激活后再运行课程
- **mypy/ruff 课报找不到模块**：第 58 章通过子进程调用工具，需确认虚拟环境已安装 `mypy`、`ruff`
- **PPT/图片课没有留下文件**：这些课程用 `TemporaryDirectory` 生成并清理演示产物，属正常行为；按课内代码改成固定路径即可保留
- **运行后根目录多了 db/csv/png**：少数原课程（如 210、数据分析图表课、177~184）按设计把产物输出到当前目录，查看后手动删除即可；63 章以后的扩展课程一律走临时目录
- **091/178/179 等报 401 / 认证错误**：这些课调用 DeepSeek，需配置 `DEEPSEEK_API_KEY` 环境变量后再运行（预期行为）
- **174~184 运行后一直不退出**：FastAPI 课程启动了 Web 服务，属预期；Ctrl+C 停止即可
- **097 连接失败**：需要本地先启动 Ollama（`ollama serve`）并拉取模型
