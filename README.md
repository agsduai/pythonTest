
## 常见问题

- **pytest 运行报 "No module named '2xx'"**：课程文件名以数字开头，需加 `--import-mode=importlib`，例如
  `pytest "214.xxx.py" --import-mode=importlib -v`
- **Matplotlib 中文变方块**：加两行配置
  `plt.rcParams["font.sans-serif"] = ["Microsoft YaHei"]`、`plt.rcParams["axes.unicode_minus"] = False`
- **GUI 窗口一闪而过**：308-315 课默认演示模式会自动关窗；把 `AUTO_DEMO` 改成 `False` 或删除 `root.after(...destroy)` 即可手动操作
- **Git 课程提示目录已存在**：课程在临时目录 `git_demo_2xx` 中运行，若上次异常中断，删除该目录即可（源码内已用 `force_rmtree` 处理只读对象）
- **pip 安装慢/断连**：使用清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple`
- **虚拟环境位置**：`pyproject01/.venv`，不影响系统中其他 Python 环境
